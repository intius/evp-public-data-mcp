# Privacy policy

Last updated: 2026-11-25

## Summary

EVP Public Data MCP does not intentionally collect analytics, advertising identifiers, or telemetry. The local server runs on the user's machine and calls Apify only when the user invokes a tool. The hosted endpoint and underlying Actors are operated by Apify.

## Information processed

- **Apify credentials.** The user's Apify token or OAuth session is supplied by the user's MCP client and is used only to authenticate requests to Apify. Credentials are not included in the package or repository.
- **Tool inputs.** Search terms, filters, and item limits are sent to Apify so the selected public data extractor can run.
- **Tool outputs.** Results are public-source records returned through Apify datasets. Run and dataset retention is controlled by the user's Apify account settings.
- **Documentation access.** The documentation site is static and hosted on GitHub Pages. GitHub may process standard hosting logs under its own privacy terms.

## What this server does not do

- It does not include advertising trackers or analytics beacons.
- It does not run background scraping jobs.
- It does not sell or share credentials with unrelated third parties.
- It does not retain extraction results outside the user's MCP client and Apify account.

## Third-party processing

Apify processes authentication, Actor runs, datasets, billing, and logs. Review [Apify's privacy policy](https://docs.apify.com/legal/privacy-policy) before using the hosted endpoint or running an Actor. GitHub processes repository, release, and GitHub Pages traffic under GitHub's privacy terms.

## Security and contact

Use client-side secret storage for Apify tokens, start with small item limits, and rotate tokens if they may have been exposed. Report security or privacy concerns through [the repository issue tracker](https://github.com/intius/evp-public-data-mcp/issues) or the security policy in this repository.
